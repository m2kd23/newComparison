# 신구조문대비표 생성기

사규(법령 형식) 현행·개정안을 붙여넣으면 신구조문대비표를 자동으로 만드는 단일 HTML 도구입니다.
인터넷이 안 되는 내부망 PC에서 크롬·엣지로 열어 사용하며, 입력 내용은 어디에도 저장·전송하지 않습니다.

## 사용
1. `신구조문대비표_생성기.html` 을 브라우저로 연다.
2. 한글에서 현행·개정안을 각각 Ctrl+A → Ctrl+C 해서 두 칸에 붙여넣는다.
3. [대비표 만들기] → [표 복사] 또는 [한글 파일로 저장 (.hwpx)].

자세한 사용법: `docs/신구조문대비표_생성기_사용방법.pptx`

## 주요 기능
- 조·항·호·목·세목 구조 인식, 조 번호 기준 비교
- (생  략)/(현행과 같음) 범위 묶음, <신  설>, <삭  제>, <단서 신설>·<후단 신설>
- 변경 부분 밑줄, 현행 빨강 / 개정안 파랑
- 조 단위 테두리
- 한글에 붙여넣기용 표 복사, .hwpx 직접 저장
- 개정 연혁 표시(<개정 …>, [본조신설 …]) 자동 제거, 부칙·별표 이후 제외

## 구조
| 경로 | 내용 |
|---|---|
| `신구조문대비표_생성기.html` | 배포용 단일 파일 (빌드 결과) |
| `src/core.js` | 파싱·비교 엔진 |
| `src/hwpx.js` | HWPX(한글) 파일 생성, 무압축 ZIP |
| `src/ui.html` | 화면 |
| `build.py` | `python build.py` 로 단일 HTML 생성 |

## 검증
개인정보 보호법(법률 제16930호 → 제19234호) 법제처 신구조문대비표와 비교해, 입력 버전 차이(시행일 미도래 조문)를 제외한 316행이 모두 일치.
