# 신구조문대비표 생성기

사규(법령 형식)의 **현행**과 **개정안**을 붙여넣기만 하면 **신구조문대비표**를 자동으로 만들어 주는 단일 HTML 도구입니다.
인터넷이 안 되는 내부망 PC에서 크롬·엣지로 파일을 열어 바로 사용합니다.

## 왜 "붙여넣기" 방식인가

내부망 PC에는 문서 암호화(DRM)가 걸려 있어서, 한글 파일(.hwp/.hwpx)을 브라우저나 다른 프로그램에 그대로 드래그앤드롭하면 내용을 읽을 수 없습니다.
파일을 넣으려면 매번 **암호화 해제를 신청하고 기다리는 번거로움**이 생깁니다.

이 생성기는 파일을 직접 읽지 않고, **한글에서 연 문서의 내용을 복사(Ctrl+A → Ctrl+C)해서 붙여넣는 방식**으로 이 문제를 해결합니다.

- 한글은 암호화된 문서를 정상적으로 열 수 있으므로, 화면에 보이는 내용을 복사하는 데는 제한이 없습니다.
- 생성기는 붙여넣은 글자만 처리하므로 **암호화 해제 절차가 필요 없습니다.**
- 원본 파일은 건드리지 않으며, 보안 정책을 우회하거나 해제하지 않습니다.
- 결과물(대비표)은 한글에 다시 붙여넣거나 .hwpx로 저장한 뒤 한글에서 저장하면, 평소처럼 사내 암호화 정책이 그대로 적용됩니다.

## 특징

- **설치 불필요**: HTML 파일 하나. 더블클릭해서 브라우저로 열면 끝
- **인터넷 불필요**: 외부 라이브러리·서버 호출이 전혀 없음. 내부망 단독 PC에서 동작
- **정보 유출 없음**: 붙여넣은 내용은 브라우저 안에서만 처리되고 어디에도 저장·전송되지 않음
- **법제처 작성 규칙 자동 적용**: 사람이 하던 대조·표 작성 작업을 자동화

## 사용 방법

1. `신구조문대비표_생성기.html` 을 크롬 또는 엣지로 엽니다.
2. 현행 규정 한글 문서에서 **Ctrl+A → Ctrl+C**, 생성기의 **[현행]** 칸에 **Ctrl+V**
3. 개정안도 같은 방법으로 **[개정안]** 칸에 붙여넣습니다.
   - 칸 아래에 `조문 N개`가 표시되면 정상적으로 인식된 것입니다.
4. 필요하면 표시 옵션을 조정합니다. (기본값 그대로 사용해도 됩니다)
5. **[대비표 만들기]** 를 누르면 바뀐 조문만 골라 대비표가 만들어집니다.
6. 결과 확인 후 둘 중 하나로 활용합니다.
   - **[표 복사 (한글에 붙여넣기)]** → 한글 문서에서 Ctrl+V
   - **[한글 파일로 저장 (.hwpx)]** → `규정명_신구조문대비표.hwpx` 로 저장

자세한 화면 안내: [`docs/신구조문대비표_생성기_사용방법.pptx`](docs/)

## 대비표 작성 규칙 (자동 적용)

| 구분 | 표시 방법 |
|---|---|
| 바뀐 부분 | 현행 **빨강**, 개정안 **파랑** + 밑줄 (단어 단위 비교) |
| 그대로인 항·호 | 현행 `(생  략)` / 개정안 `(현행과 같음)` |
| 연속으로 그대로인 항목 | `1. ∼ 6.`(3개 이상), `①·②`(2개)처럼 범위로 묶음 |
| 새로 생긴 조·항·호 | 현행 쪽에 `<신  설>` |
| 없어진 조·항·호 | 개정안 쪽에 `<삭  제>` |
| 단서·후단만 추가 | 현행 문장 끝에 `<단서 신설>` / `<후단 신설>` |
| 조 제목 변경 | `제N조(새 제목) ① (현행과 같음)` 형태로 표시 |
| 장·절 제목 변경 | 별도 행으로 표시 (옵션) |
| 테두리 | 조 단위로 가로선, 조 안의 행 사이는 선 없음 |

## 인식하는 조문 형식

| 단위 | 예시 |
|---|---|
| 장·절·관 | `제1장 총칙`, `제2절 …` |
| 조 | `제1조(목적)`, `제3조의2(정의)`, `제5조 삭제` |
| 항 | `①` ~ `㊿` |
| 호 | `1.`, `2의2.` |
| 목 | `가.`, `나의2.` |
| 세목 | `1)`, `가)`, `(1)`, `(가)` |

- 번호가 없는 문단은 바로 앞 항목에 이어지는 내용으로 처리합니다.
- 법제처 원문에 붙는 `<개정 2024. 1. 1.>`, `[본조신설 …]`, `[시행일: …]` 같은 연혁 표시는 자동으로 제거하고 비교합니다. (옵션)
- `부칙`, `별표`, `별지` 이후 내용은 비교에서 제외합니다.
- 문서 맨 앞 줄에서 규정명을 자동으로 찾아 대비표 제목(`「규정명」 신구조문대비표`)으로 씁니다.

## 결과 확인·수정

- 개정·신설·삭제 조문 수가 화면에 표시됩니다.
- **[확인이 필요한 항목]** 에 조·항 번호 순서 이상, 번호 없는 문단이 많은 경우 등이 안내됩니다.
- **[인식한 조문 구조 보기]** 로 조·항·호가 원문대로 인식됐는지 확인할 수 있습니다.
- 대비표 미리보기는 클릭해서 **바로 고칠 수 있고**, 고친 글자·색·밑줄은 복사·한글 저장에 그대로 반영됩니다.

## 한글(.hwpx) 저장

- 브라우저 안에서 HWPX(한글 표준 문서 형식)를 직접 만들어 저장합니다. 별도 프로그램 불필요.
- A4 세로, 제목 행(`현 행` / `개 정 안`)은 쪽이 넘어가면 반복, 표 서식(글꼴·크기)은 옵션에서 지정
- 생성한 파일은 한글 문서 형식 검사(스키마·패키지 검증)를 통과했습니다.

## 유의사항

- 조문은 **조 번호끼리** 짝지어 비교합니다(법제처 대비표와 같은 방식). 중간에 조가 끼어들어 뒤 조 번호가 모두 밀리는 전부개정에서는 밀린 조들이 모두 개정으로 표시됩니다.
- 한글의 **자동 문단번호**(①, 1. 등)는 복사할 때 빠질 수 있습니다. 번호가 글자로 입력되어 있어야 정확히 인식됩니다.
- 완성된 대비표는 담당자가 최종 검토한 뒤 사용하세요.

## 검증

- 개인정보 보호법(법률 제16930호 → 제19234호)으로 만든 결과를 법제처 신구조문대비표와 행 단위로 대조:
  입력 버전 차이(시행일이 늦은 조문 미포함)로 생긴 행을 제외한 **316행 모두 일치**
- 공공데이터법(법률 제19408호 → 제21392호): 원문 줄 단위 비교 결과와 변경 조문(제5조·제6조·제29조) 일치

## 파일 구성

| 경로 | 내용 |
|---|---|
| `신구조문대비표_생성기.html` | 배포용 단일 파일 (빌드 결과) |
| `src/core.js` | 조문 구조 인식·비교·변경 부분 표시 엔진 |
| `src/hwpx.js` | HWPX(한글) 파일 생성, 무압축 ZIP 작성 |
| `src/ui.html` | 화면 |
| `build.py` | `python build.py` 로 src를 합쳐 단일 HTML 생성 |
| `docs/` | 사용방법 가이드(PPT) |

## 개발

```bash
# src/ 수정 후 단일 HTML 다시 만들기
```
